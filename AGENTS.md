# Repository workflow

- Use a `codex/` feature branch for changes
- Changes must go through a pull request; never push directly to the default branch
- Do not push or open a remote PR until the user authorizes pushing
- This app is a clickable case-competition prototype; simulated school imports are intentional
- Follow the original Speqq neutral design: no purple gradients, dotted backgrounds, or periods at the ends of headings
